# Stellar Burgers API Tests

## Описание проекта

Проект содержит автоматизированные API-тесты для сервиса Stellar Burgers.

Тесты написаны на Python с использованием pytest и requests. Для формирования отчётов используется Allure.

## Проверяемые сценарии

### Создание пользователя

* Успешная регистрация уникального пользователя.
* Повторная регистрация существующего пользователя.
* Регистрация без обязательного поля.

### Авторизация

* Успешный вход зарегистрированного пользователя.
* Вход с неправильными учётными данными.

### Создание заказа

* Создание заказа авторизованным пользователем.
* Создание заказа без авторизации.
* Создание заказа с ингредиентами.
* Создание заказа без ингредиентов.
* Создание заказа с неверным хешем ингредиента.

## Технологии

* Python 3.12
* pytest
* requests
* allure-pytest

## Установка и запуск

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение:
   python -m venv .venv
3. Установите зависимости:
   python -m pip install -r requirements.txt
4. Запустите все тесты:
   python -m pytest tests -v
   

## Формирование Allure-отчёта

Для сохранения результатов тестирования выполните:
python -m pytest tests --alluredir=allure-results

Для просмотра отчёта при установленном Allure Commandline:
allure serve allure-results
